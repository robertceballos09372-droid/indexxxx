jQuery

jQuery es una biblioteca de JavaScript creada para facilitar tareas frecuentes como seleccionar elementos, manejar eventos, realizar animaciones y modificar páginas web.

¿Por qué nació jQuery?

jQuery surgió para simplificar el desarrollo web y facilitar el trabajo con diferentes navegadores mediante una sintaxis más sencilla.

Sintaxis básica


$("#mensaje").hide();

$("#boton").click(function() {
    $("#mensaje").show();
});

JavaScript vs jQuery

JavaScript Vanilla jQuery
document.getElementById("mensaje") $("#mensaje")
elemento.style.display = "none"; $("#mensaje").hide();
elemento.addEventListener("click", funcion); $("#boton").click(funcion);

Ventajas

  • Sintaxis sencilla.
  • Facilita la manipulación del DOM.
  • Incluye métodos para animaciones.
  • Facilita algunas tareas comunes.

Desventajas

  • Es necesario cargar una biblioteca adicional.
  • JavaScript moderno puede realizar muchas tareas sin jQuery.
  • Algunos proyectos actuales prefieren JavaScript Vanilla.
