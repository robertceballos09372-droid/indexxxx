JSON

JSON significa JavaScript Object Notation. Es un formato ligero utilizado para almacenar y transmitir información.

¿Por qué es importante?

JSON es muy utilizado para intercambiar información entre una página web y un servidor o una API.

Objeto JavaScript


const pizza = {
    nombre: "Pizza Suprema",
    precio: 12.50,
    disponible: true
};

Cadena JSON


{
    "nombre": "Pizza Suprema",
    "precio": 12.50,
    "disponible": true
}

Estructura de JSON

🔑 Clave

Es el nombre que identifica un dato.

📦 Valor

Es la información almacenada.

📋 Arreglos

Permiten almacenar varios valores utilizando corchetes.

🗂️ Objetos

Permiten organizar información mediante pares clave-valor.

Ejemplo de un menú de Pizza Bonilla


{
    "pizzas": [
        {
            "nombre": "Pizza Pepperoni",
            "precio": 8.00
        },
        {
            "nombre": "Pizza Suprema",
            "precio": 12.50
        },
        {
            "nombre": "Pizza Hawaiana",
            "precio": 9.00
        }
    ]
}

JSON y las APIs

Una aplicación web puede solicitar información a un servidor. El servidor puede responder utilizando datos en formato JSON. De esta forma, la página puede recibir información como productos, precios, usuarios o pedidos.
