JavaScript Vanilla

JavaScript es un lenguaje de programación utilizado principalmente para agregar comportamiento e interactividad a las páginas web.

HTML, CSS y JavaScript

Tecnología Función
HTML Define la estructura de la página.
CSS Define los estilos y apariencia.
JavaScript Agrega comportamiento e interactividad.

Conceptos básicos

Variables

Permiten almacenar información que puede utilizar el programa.

Funciones

Son bloques de código que realizan una tarea determinada.

Eventos

Permiten ejecutar código cuando sucede algo, como hacer clic sobre un botón.

Ejemplo práctico


function mostrarPizza() {
    alert("¡Bienvenido a Pizza Bonilla!");
}

document.getElementById("boton")
    .addEventListener("click", mostrarPizza);

¿Para qué se utiliza?

  • Crear botones interactivos.
  • Validar formularios.
  • Crear animaciones.
  • Modificar contenido de una página.
  • Crear aplicaciones web.
  • Comunicar una página con servidores y APIs.
