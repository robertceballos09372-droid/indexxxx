Web Hosting y Dominios

¿Qué es Web Hosting?

El Web Hosting es un servicio que permite almacenar los archivos de un sitio web en un servidor conectado a Internet.

Tipos de Hosting

🏠 Hosting compartido

Varios sitios web utilizan los recursos de un mismo servidor. Es una opción económica.

🖥️ VPS

Un servidor físico se divide en servidores virtuales independientes.

☁️ Hosting en la nube

Utiliza recursos distribuidos en diferentes servidores conectados mediante una infraestructura de nube.

¿Qué es Vercel?

Vercel es una plataforma utilizada para desplegar aplicaciones y sitios web. Puede conectarse con un repositorio de GitHub para publicar un proyecto y generar una dirección web.

¿Qué es un dominio?

Un dominio es el nombre que las personas utilizan para acceder fácilmente a un sitio web en Internet.

Ejemplos de TLD

TLD Ejemplo
.com pizzalla.com
.net pizzailla.net
.org pizzalla.org

¿Qué es un subdominio?

Un subdominio es una parte adicional de un dominio que permite organizar diferentes secciones de un sitio web.

Ejemplo: blog.pizzajhhh.com

Propagación DNS

🌐 Dominio
↓
🔎 DNS
↓
🖥️ Servidor
↓
🍕 Sitio web

Cuando se configura un dominio, los registros DNS necesitan actualizarse y distribuirse para que diferentes servidores puedan encontrar la dirección correcta del sitio web.

Proceso para publicar Pizza Bonilla

  1. Crear el sitio web.
  2. Crear un repositorio en GitHub.
  3. Subir los archivos del proyecto.
  4. Conectar GitHub con Vercel.
  5. Realizar el despliegue.
  6. Obtener la URL pública.
